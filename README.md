# network

文化政策ニュースの共起ネットワーク分析基盤。

世界各国のニュース・政策発表を自動収集し、テキスト分析して共起ネットワークを構築する。
「今日どのキーワードが頻出しているか」「それがどの文化施設・政策に結びついているか」
「語と語の関係がどう変化したか」を日次で可視化することを目的とする。

フェーズ1の対象は**日本の文化政策**。
