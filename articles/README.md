# articles/ — ここに記事を置く

このディレクトリにファイルを置いて push すると、GitHub Actions が自動で分析し、
`out/` に共起ネットワーク（GEXF / HTML / CSV / レポート）を書き戻します。

## 対応形式

| 拡張子 | 内容 |
|---|---|
| `.txt` `.md` | YAML フロントマター（任意）+ 本文。1ファイル = 1記事 |
| `.html` | 保存したWebページ。`<title>` と本文テキストを自動抽出 |
| `.json` | 記事オブジェクト、またはその配列。1ファイルに複数記事 |
| `.jsonl` | 1行1記事のJSON |
| `.csv` `.tsv` | ヘッダ行付きの表。1行1記事 |

サブディレクトリを作っても構いません（`articles/2026-08/` など）。
`_` や `.` で始まるファイル・フォルダと `README.md` は対象外です。

## いちばん簡単な置き方（.md）

````markdown
---
title: 文化審議会が博物館法の運用見直しを議論
date: 2026-08-12
source: 文化庁
url: https://example.com/news/12345
tags: [博物館, 法改正]
---

文化審議会博物館部会は12日、登録博物館制度の運用について議論した。
学芸員の配置要件を巡り、地方の中小館から負担を懸念する声が上がった。
（以下、記事本文）
````

フロントマターは全部省略できます。その場合は先頭行を見出しとみなし、
日付はファイル名（例: `2026-08-12_hakubutsukan.md`）から拾います。

## 表でまとめて置く（.csv）

```csv
title,body,date,source,url
文化審議会が博物館法の運用見直しを議論,文化審議会博物館部会は12日…,2026-08-12,文化庁,https://example.com/1
文化観光拠点の整備計画を3件認定,観光庁と文化庁は…,2026-08-10,観光庁,https://example.com/2
```

列名は `title/body/date/source/url` のほか、`見出し/本文/日付/出典/リンク`、
`headline/text/published_at/publisher/link` でも認識します。

## 分析のコツ

- **日付を入れると価値が跳ね上がります。** 直近とそれ以前を比べた
  「急に強まった結びつき（surprise）」が出せるのは日付があるときだけです。
- **見出しは必ず入れてください。** 本文より情報密度が高く、共起の質に直接効きます。
- 記事が少ないうち（30本未満）は `config.yaml` の `min_df` を 2 に下げてください。
  既定値（3）のままだと、ノードがほとんど残りません。
- 同じ本文のファイルを複数置いても、重複として1件にまとめられます。

## 著作権について

報道記事の**全文をこのリポジトリに置くと再配布にあたります**。
リポジトリを公開する場合は、見出し + リード + URL までに留めるか、
リポジトリを private にしてください。官公庁の報道発表資料は全文で問題ありません。
